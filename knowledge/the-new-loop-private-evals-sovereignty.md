# The New Loop. Private Evals as Sovereignty (Andy Hall)

Attribution: this is a doc-mine of Andy Hall's essay "Teaching the New Loop" (freesystems.substack).
Credit the original author; this file is notes + a reframe, not a substitute for the essay.

## Thesis
As frontier models commoditize expert knowledge, an org keeps independence by codifying its expertise
into **private evals it owns**: measure ANY model against YOUR goals, iterate against that measurement,
and switch models without losing the accumulated "company-veteran" knowledge. Framed as political
economy, not just strategy: owned evals = sovereignty / avoiding capture by a single lab. Closes on
AI-literacy-as-civics ("Republic of builders").

**Sharpest lines:**
- "Without human direction, you have compute running in circles." (Nadella)
- "A company should be able to switch out a 'generalist' model without losing the 'company veteran'
  expertise." (Nadella, via Hall)
- "Critical thinking is the thing that makes the AI worth anything at all."

**Hall's 4 teaching lessons:** domain-expertise + critical-thinking are prerequisites not obstacles /
scaffolding before independence / in-person real-time tutoring accelerates / people underestimate their
capacity to build evals. Class process: identify eval criteria -> design scoring rubrics -> build model
leaderboards -> embed evals into the tools that decide.

## How this maps to a memory + skills + eval stack
A stack that already runs the relevant primitives is most of the way there:
- A **private eval layer**: a multi-metric eval harness, a reality-feedback ledger, a
  calibration/confidence layer, a periodic skill-eval cron, per-pipeline output rubrics, and a
  tool-grounded critic gate.
- **Model-portability, lived**: migration evals run whenever a model-swap decision comes up, a
  cron/effort model-tiering build, MCP-OAuth portability classes (portable vs credential-coupled),
  subscription-first provider posture.
- **Evals embedded in tools that decide**: critic gates + a stake classifier + calibrated abstention.

If those exist, the net-new *mechanism* from this essay is small; the value is the reframe below.

## The reusable lifts
1. **The REFRAME (adopt as a principle).** Evals are usually built ad-hoc, per-pipeline. Hall's lens:
   treat the whole **eval + memory + skills** layer as ONE deliberate model-switch-insurance asset, the
   "company veteran" that must survive a frontier-model swap intact. Implication when you evaluate a
   model migration: the test isn't "is the new model smarter," it's "does our owned eval+memory+skills
   layer score it acceptably against OUR goals, and does the layer carry over cleanly." Don't re-derive
   expertise into a new model. port the eval+memory+skills and re-score.
2. **External validation of the harness-is-the-moat thesis.** As raw model intelligence hits
   diminishing returns, the durable moat migrates off the model to the harness + owned-context +
   distribution. "The new loop" is that thesis, named by an outside source. Useful as a citeable
   third-party anchor when the moat-migrates-off-the-model argument comes up.

## What this does NOT add
- No new tool/build if you already run the eval primitives.
- The "Republic of builders" / AI-literacy-civics framing is thematic, not a concrete artifact.
