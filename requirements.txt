# Utopia OS core dependencies
#
# THIS FILE IS INTENTIONALLY EMPTY OF HARD REQUIREMENTS, and that is a design property
# rather than an oversight.
#
# Measured on the current tree: all 48 Python modules under scripts/ import cleanly with
# NO third-party packages installed at all. The memory system is Markdown files, the state
# store is stdlib sqlite3, the security gates are stdlib, and the cockpit is stdlib
# http.server. You can clone this repo and run the core with nothing but Python 3.9+.
#
# Everything third-party is either OPTIONAL WITH A FALLBACK (listed below) or confined to
# the one file that needs it (see requirements-memory.txt). Install only what you use.
#
#   pip install -r requirements.txt              # this file: nothing required
#   pip install -r requirements-memory.txt       # semantic recall, multi-GB, one file
#
# ---------------------------------------------------------------------------------------
# OPTIONAL. Each of these is imported inside a try/except with a working fallback, so the
# system runs without them. Uncomment what you want.
# ---------------------------------------------------------------------------------------

# Loads a .env file for the critic dispatch hook. Without it, export the variables in your
# shell instead. Used by: scripts/eval/critic_dispatch_hook.py

# Timezone data for Python 3.8 and older ONLY. Python 3.9+ has zoneinfo in the stdlib and

# backports.zoneinfo>=0.2.1; python_version < "3.9"

# ---------------------------------------------------------------------------------------
# PLATFORM NOTE
# ---------------------------------------------------------------------------------------
# scripts/memory/lib_signal_store.py uses fcntl for its cross-process file lock. fcntl is
# POSIX-only. On native Windows the module still imports and runs, but the lock degrades to
# a no-op and concurrent writers are no longer serialised. Run under WSL2 on Windows. See
# QUICKSTART.md for the full platform matrix.
