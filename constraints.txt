# Utopia OS install constraints
#
# A constraints file pins versions without asking for anything to be installed. pip applies a
# pin only when a requirement pulls that package in, so this file is safe to pass with any
# requirements file in the repo:
#
#   pip install -r scripts/mcp/graph_mcp/requirements.txt -c constraints.txt
#
# scripts/mcp/graph_mcp/requirements.txt already names this file on a -c line, so a plain
# `pip install -r scripts/mcp/graph_mcp/requirements.txt` applies it too.
#
# WHAT IS PINNED. The full dependency set of the graph server's optional SDK transport
# (mcp and everything it pulls in), so `--sdk` installs the exact set `--selftest-sdk` passed
# on. An unconstrained resolve picks the newest release of every transitive package, and some
# of those can be a day old.
#
# THE RULE FOR EACH PIN. Every version here was on PyPI for at least 7 days when it was set,
# and a version-specific OSV query (api.osv.dev) for it returned no advisories. To move a pin,
# check both again for the new version, then re-run `server.py --selftest-sdk`.
#
# SCOPE. Resolved on Linux with CPython 3.12. Another OS or Python version can need packages
# that are not listed (for example pywin32 on Windows); pip installs those unconstrained.
# requirements-memory.txt does not use this file.
